# 诺瓦 Nova · 学生日程助理

诺瓦把"我想考过 XX"变成每天做得完的任务：用自然语言说明目标、截止日与可投入时间，确定性引擎评估可行性并排出 30 分钟粒度的日程；执行时计时记录，落后时预览重排，周末生成周报复盘。

**本地优先**：无账号、无云同步，业务数据只存在你自己的设备上。排程与重排全部由确定性引擎完成——相同输入必得相同输出，每一步可解释、可复现。可选接入 LLM，但它只负责澄清需求与建议拆解，日程块始终由引擎生成。界面为黏土质感设计，配 WebGL 舞台与吉祥物诺瓦形象。

## 功能总览

| 页面 | 能做什么 |
|---|---|
| 对话 | 自然语言新建目标、查询与下达指令；未配置 LLM 时自动降级为四步表单 |
| 今日 | 计时执行、记录完成度、补录与暂缓；落后时说"帮我重排" |
| 计划 | 查看整周安排，拖动改期、锁定关键任务 |
| 数据 | 周报与归因分析，看清时间花在哪里 |
| 我的 | 每周可用时段、CSV 导出、JSON 备份/恢复、显示与动效偏好 |

可行性以利用率 R 评估：≥1.2 充裕、≥0.9 合理、≥0.7 偏紧，低于 0.7 需先校准目标或时间。重排按"顺延→压缩→替代→放弃"四级预览，确认后生效且可撤销；锁定项不参与重排，放弃需再次确认。

## 快速开始

**方式一：零依赖体验**

双击 `index.html` 即可在浏览器中使用，排程、记录、撤销、备份全部离线可用。

**方式二：完整服务**（推荐，需 Node.js 22+）

```bash
npm start    # 零第三方依赖，无需 npm install
# 访问 http://127.0.0.1:8787/
```

**可选：接入 LLM**

通过环境变量注入 OpenAI 兼容服务商的三要素 `LLM_BASE_URL`、`LLM_API_KEY`、`LLM_MODEL`，即可启用对话式澄清与拆解建议；缺任一项时自动降级为表单流程，其余功能不受影响。项目不自动读取 `.env` 文件，变量模板见 [.env.example](.env.example)。

## 数据与隐私

- **数据在本机**：业务主数据存于浏览器本地；服务端仅提供健康检查、鉴权与计算能力，默认只监听 `127.0.0.1`。数据无云端副本，清理浏览器数据或换设备前，请先在"我的"导出 JSON 备份。
- **密钥安全**：LLM API Key 只在服务端进程内使用，不下发前端、不入库；`.env` 已被 `.gitignore` 忽略。不要把密钥写进代码或提交到仓库。
- **生产环境**：`NODE_ENV=production` 时必须配置 ≥32 字节随机串 `NOVA_AUTH_SECRET`，否则服务拒绝启动。
- **不要直接公网暴露**：本项目按本机自用设计。如需局域网/公网访问，请参考 [deploy/nginx.conf.example](deploy/nginx.conf.example) 通过反向代理收紧边界，并按需配置 `NOVA_ALLOWED_ORIGINS`、`NOVA_TRUST_PROXY` 等环境变量。

## 开发

- `npm test` 运行全量测试（引擎单测、HTTP 冒烟、前端 VM 测试、资产门禁）
- `npm run dev` 启动监听服务；`npm run audit` 运行 CSS 审计
- 修改 `shared/engine/` 后执行 `npm run build:engine` 生成产物，勿手改 `assets/js/rhythm.build.js`
