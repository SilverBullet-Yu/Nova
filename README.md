# 诺瓦 Nova · 学生日程助理

## 项目简介

面向学生的、可运行、可解释、可复现的日程助理 Demo：左侧对话栏用自然语言驱动右侧工作台，**浏览器本地 overlay 是唯一业务主数据**；服务端只提供健康检查、鉴权与可行性 / 排程 / 重排 / 归因 / LLM 等计算调用，只接收计算所需参数，不持久化业务主数据。**同一套引擎代码**既供服务端计算，也供前端本地降级。目标工作流：**多轮澄清意图（从整体到局部）→ 汇总确认需求 → 结合执行记录制订计划（可手动调整）→ 可视化并鼓励逐步完成**。

> **定位**：澄清对话与计划拆解建议由 LLM 承接（OpenAI 兼容接口，可配置、可降级）；排程 / 重排 / 归因全部由纯函数计算——相同输入必得相同输出，每个排程决策都附一句人类可读的理由，LLM 不产出任何排程块。未配置 LLM（或离线）时自动降级为关键词 + 四步表单流程，功能不缺失。
>
> **能力**：对话式需求澄清（诺瓦逐层追问：目标 → 截止 → 可投入时间 → 现状水平 → 科目偏好，画像齐备后汇总确认）、目标落地与可行性判定（`R` 四档，`< 0.7` 阻断并给校准路径）、LLM 拆解建议（科目/时长分配 + 风险提示，经边界校验后由引擎排程）、30 分钟粒度自动排程、四级重排（L1 顺延 → L2 压缩 → L3 替代 → L4 放弃）与本机快照撤销、连续 ≥ 3 天无记录的中断挽救、偏差归因、执行记录与周报、7×4 可用时段设置、离线与移动端适配。助理人格「诺瓦」以待机 / 计算中 / 专注 / 达成 / 挽救 / 提醒 / 兜底七个状态立绘，配合待机 / 聆听 / 离线三枚头像与站点图标呈现：用户输入时诺瓦换聆听形象，离线时顶栏换为离线褪色形象；旧队列只显示隔离数量，不表示存在上行任务，设定见 [`docs/IP-DESIGN.md`](docs/IP-DESIGN.md)。

## 快速部署与使用

### 方式一：只开前端（零环境）

双击 `index.html` 即可使用本地主数据与本地引擎；页面只探测 `http://127.0.0.1:8787` 的 `/api/health`，后端不可达时显示「离线 · 本地可用」，排程、记录、确认、撤销和备份均不依赖服务端。

### 方式二：前后端完整运行

```bash
npm start     # 启动服务，默认端口 8787
npm test      # 引擎单测 + HTTP 冒烟
```

打开 `http://127.0.0.1:8787/`：服务同时静态托管前端，前后端同源；健康探测成功后顶栏显示「本地主数据 · 服务端仅计算」（存在旧 pending 时改为隔离数量提示），该状态只表示计算服务可达，不表示业务数据已上传或同步。

**环境要求**：Node.js **22+**（仅 `npm start` / `npm test` 需要，双击打开 `index.html` 不需要任何环境）；**服务端零第三方运行时依赖**——只用 `node:http` / `node:fs` / `node:path` / `node:url` / `node:crypto` 等内置能力；前端使用仓内 vendored Three.js r152.2（包版本 `0.152.2`）与 CSS3DRenderer（`assets/vendor/`），不依赖 CDN。运行现有项目无需 `npm install`，不代表全栈零第三方。

| 命令 | 作用 |
|---|---|
| `npm start` | 启动 HTTP 服务（API + 静态托管前端） |
| `npm test` | 引擎单测 + HTTP 端到端冒烟 + 形象素材门禁 |
| `npm run build:engine` | 由 `shared/engine/*.js` 生成浏览器引擎产物（**改过引擎必须重跑**） |
| `npm run check:engine` | 只读校验浏览器引擎产物与源码同步 |
| `npm run bench:replan` | 运行 8–500 任务有界重排基准；异常或超过软预算时非零退出 |
| `npm run bench:placement` | 对比 100/500 任务逐次查询与批量分段索引耗时 |
| `npm run audit` | CSS 审计 |

### 环境变量

本项目不自动读取 `.env`（服务端未引入第三方环境变量加载器），请通过 shell 或系统环境变量注入；清单见 [`.env.example`](.env.example)（只含变量名与说明，无真实值，`.env` 已被 `.gitignore` 忽略）。

| 变量 | 缺省 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口（`server/main.js` 的 `DEFAULT_PORT`） |
| `HOST` | `127.0.0.1` | 监听地址（`DEFAULT_HOST`）；需要局域网或反向代理访问时显式覆盖 |
| `NOVA_AUTH_SECRET` | 本地随机 / 生产必填 | 凭证 HMAC 密钥，需 ≥32 字节随机串；`NODE_ENV=production` 未配置直接拒绝启动 |
| `NOVA_STORE_FILE` | `server/data/nova-store.json` | 服务端 JSON 存储路径；进程启动时读取，写入时以临时文件替换 |
| `NOVA_STORE_PARTITIONED` | `0` | 设为 `1` 启用内容寻址分区布局；写入 `.partitioned.json` 模式标记，标记/manifest/parts 不一致时拒绝回退旧 JSON |
| `NOVA_STORE_MAX_BYTES` | `16777216` | 持久化字节预算；legacy 计算当前 JSON，partitioned 计算 manifest、标记与全部 parts（含旧版本/孤儿） |
| `NOVA_STORE_MAX_PARTITIONS` | `1024` | 匿名身份可创建的最大分区数 |
| `NOVA_DRAFT_BUDGET_BYTES` | `8388608` | 进程内重排草案总字节预算，超限 FIFO 淘汰 |
| `NOVA_RECEIPT_BUDGET_BYTES` | `4194304` | 进程内复核收据总字节预算，超限 FIFO 淘汰 |
| `NOVA_STORE_LOCK_TIMEOUT_MS` | `5000` | 共享存储锁等待上限；超时不自动删除无法确认归属的锁 |
| `NOVA_HTTP_HEADERS_TIMEOUT_MS` | `10000` | Node 请求头超时，范围 1000–60000ms |
| `NOVA_HTTP_REQUEST_TIMEOUT_MS` | `130000` | Node 完整请求超时，范围 1000–300000ms |
| `NOVA_HTTP_KEEP_ALIVE_TIMEOUT_MS` | `5000` | Node keep-alive 超时，范围 1000–60000ms |
| `NOVA_HTTP_MAX_CONNECTIONS` | `128` | Node 最大连接数，范围 1–10000 |
| `NOVA_TRUST_PROXY` | 未设置 | 置于网关 / 反代之后时设为 `1`，按 `X-Forwarded-For` 最后一跳隔离限流桶；不设则按不可伪造的 TCP 对端地址 |
| `NOVA_ALLOWED_ORIGINS` | 未设置 | 跨域精确 origin 白名单，逗号分隔；同源请求不需要 CORS 头 |
| `NOVA_ALLOW_NULL_ORIGIN` | 未设置 | 设为 `1` 才允许 `file://` 的 `null` origin 跨源调用 |
| `NOVA_ADMIN_BACKUP_DIR` | `<store 目录>/nova-admin-output` | CLI 敏感备份与审计输出根目录 |
| `LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL` | 未设置 | LLM 理解与分析层（对话式澄清 + 拆解建议）。OpenAI 兼容 `/chat/completions`，任何兼容服务商均可；三要素齐备才启用，缺任一项前端自动降级为表单流程。key 只在服务端进程内使用 |
| `LLM_TIMEOUT_MS` | `30000` | 单次 LLM 调用超时（毫秒），范围 3000–120000 |
| `NOVA_LLM_MAX_REQUEST_BYTES` | `262144` | LLM 上下文请求字节上限，超限在联网前拒绝 |
| `NODE_ENV` | 未设置 | 设为 `production` 启用生产约束（鉴权密钥必填等） |

> 缺省值以 `server/main.js` 为准：`.env.example` 里的 `PORT=8080` / `HOST=127.0.0.1` 是示例取值，不是缺省端口。缺省绑定 `127.0.0.1:8787`，启动横幅打印该回环地址；需要局域网或反向代理访问时显式设置 `HOST`。

### 使用指南

顶栏为品牌、主导航（**对话 / 今日 / 计划 / 数据 / 我的**）与计算连接状态：服务可达且无旧 pending 时为圆点 + 「本地主数据 · 服务端仅计算」；有旧 pending 时显示「本地主数据 · 旧队列已隔离 N」，「我的」页显示「N 项已隔离」。离线时换为诺瓦的离线褪色形象，基础文案为「离线 · 本地可用」，有旧 pending 时附加隔离数量；不再显示待处理角标。对话页输入台左侧另有一枚诺瓦头像，用户输入时换为聆听形象。**对话是主页面**：输入自然语言或点快捷语句，诺瓦驱动其余工作台子页，消息历史跨页签保留。

| 视图 | 内容与操作 |
|---|---|
| 今日 | 任务卡、达成率、弹性位；可暂停 / 继续，结束后选 25–100% 完成度与状态，未开始可跳过，另有「补录」；「今日暂缓（未改期）」独立展示并可恢复 |
| 计划 | 新建目标 / 重新安排；可行性 `R` 与四档刻度、本周日程块（拖动改期、锁定）、未来 7 天负载；暂缓项独立可见并可恢复，不占普通日程块 |
| 数据 | 本周概览与三段式周报；8 周趋势、科目结构、偏差归因 |
| 我的 | 可用时段 7×4 网格、通知开关、CSV 导出、完整 JSON 备份与导入、删除数据（7 天内可恢复）、显示与动效 |

常用指令（关键词命中即触发，无需固定句式）：

| 你说 | 效果 |
|---|---|
| 新建目标 / 定目标 | 进入对话式澄清：诺瓦逐层追问（整体→局部），画像确认后由 LLM 给拆解建议、引擎排程；LLM 未配置时自动转四步表单 |
| 我断了四天 / 中断 / 挽救 | 进入中断挽救，缺口量化后三选一 |
| 今天学什么 / 安排 / 任务 | 列出今日任务与剩余时长 |
| 我的计划可行吗 / R 值 / 来得及吗 | 输出可行性评估与判定档位 |
| 这周落下了 / 帮我重排 / 来不及 / 崩了 | 走四级重排，给出策略、diff 与负载变化 |
| 撤销 / 恢复 / 撤回 | 回滚上一次重排 |
| 生成周报 / 复盘 / 这周怎么样 | 输出周报 |
| 确认放弃 | 在本机确认含「放弃」项的重排（L4 经确认才生效，不使用服务端 `draftId`） |

未命中任何关键词时返回兜底说明，不臆造结果。

### 使用前须知

- **本地主数据**：`zx.overlay` 是唯一业务主数据，保存目标、任务、执行记录、改期、锁定、重排历史与快照等；格式为 `nova-overlay`、版本 `3`，并带 `syncMode=local-only`、`installId`、单调 `revision` 与 `updatedAt`。`placementModel` 保存具体日期、时区和完整区块，`week` 是由区块推导的投影。旧 v1/v2 仍可读，但不会自动猜出历史区块。损坏、结构不符或未来版本会保留原键并暂停覆盖，须显式导入完整备份或确认删除后才能继续写入。
- **服务端边界**：前端启动和 `online` 事件只探测 `/api/health`；计算请求按需签发 Bearer 凭证。`getState`、服务端状态接收（`adopt`）、op 上行、计划复核、服务端重排确认 / 撤销等旧接口与数据**仅服务端保留，前端不使用**，不构成跨设备同步或云端备份。
- **本机重排与 M3 暂缓**：重排先预览，确认和快照撤销都在本机完成，服务端 `draftId` 不参与业务确认；后续任何独立修改都会使撤销整笔拒绝。`deferred` 仅表示「今日暂缓」，不是真实改期；退出今日、计划普通块、挽救与重排候选，在今日页和计划页的独立列表可见并可恢复，计划日期不变。v3 真实改期使用具体日期和完整区块；legacy 不自动迁移。
- **旧数据隔离**：`zx.op_queue` 原字节保留、只读，`queueOp` 不再写入，`pendingCount=0`；`legacyPendingCount` 统计旧 pending 并显示「N 项已隔离」。`zx.pending_plan` 只保留，不自动复核。显式删除本机业务数据也不会清除这两类旧数据。
- **备份恢复**：「我的」支持 CSV 与完整 JSON 备份（`format=nova-backup`、`version=1`）。导入前校验格式、版本、时间、安装标识与业务快照；确认覆盖前将当前快照存入 7 天 trash，写入后回读校验，失败尝试回滚并告警。备份不含 token、旧队列或旧待复核计划。
- **单人演示凭证**：计算接口使用 Bearer 凭证（由 `POST /api/auth/session` 签发），但无注册 / 多用户账户体系；凭证只用于调用计算服务，不是业务主数据身份。未配置固定 `NOVA_AUTH_SECRET` 时重启会使旧凭证失效。
- **LLM 边界**：对话式澄清与拆解建议调用外部 LLM（需配置）；拆解建议仅含「学什么 / 各科多少时间 / 风险」，R 值与排程块始终由本地引擎产出。对话画像不落盘，与对话流同生命周期（刷新即清）。
- 通知开关仅记录意图、不实际投递；CSV 与 JSON 均由浏览器本地生成；页面使用本地 vendored Three.js / CSS3DRenderer 与本地渐变背景；历史 Wikimedia 素材仅保留来源注释，不加载远程图片；无埋点、无 Cookie。接口与边界见 [交接文档](docs/HANDOFF.md)，验收见 [PRD](docs/PRD-NOVA-AGENT-EVOLUTION.md#11-mvp-验收标准)。
