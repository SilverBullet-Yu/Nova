# 诺瓦 Nova · 智能学习日程助理 Demo

> 前端 Web + 后端 API + 确定性调度引擎。对齐《MVP 技术架构文档》的六条硬约束（C1–C6）。

一个**可运行、可解释、可复现**的学习日程助理演示。前端是一个零依赖的单页工作台，左侧对话栏用自然语言驱动右侧工作台；后端提供确定性引擎与 REST API，**同一套引擎代码**同时供前端离线兜底与后端在线计算。

---

## 快速开始

### 只看前端（无需任何环境）

双击 `index.html` 即可运行。无后端时前端自动降级到本地引擎，**全部功能可用**，顶栏显示离线态。

### 完整栈（前后端联调）

```bash
npm start        # 启动后端 http://127.0.0.1:8787
npm test         # 运行引擎单测 + HTTP 冒烟
```

浏览器访问 `http://127.0.0.1:8787/` 走同源 API；直接双击 `index.html` 走 `file://` 本地引擎兜底。

**环境要求**：Node.js 22+（用到内置 `node:sqlite` 之前的版本也兼容——本项目仅用 `node:http`/`node:fs` 等稳定 API）。**零第三方依赖**。

## 架构要点

### C2 · 排程结果可解释、可复现

`shared/engine/` 下四个模块全部是**纯函数**：不读时钟、不读随机数、不做 I/O，相同输入必得相同输出。排程的每一个决策都带一句人类可读理由（`reason` 字段）。

### C4 · 写路径先落本地再上行

前端写操作先进 `localStorage` 的 op 队列（`zx.op_queue`），联网成功后才清 pending 标记；`opId` 作为幂等键，重复提交返回首次的 `serverSeq`。

### C3 · 重排可撤销

每次重排先写快照（`snapshot`），撤销即**反向应用**快照，**不重算**，保证撤销后与重排前逐条一致。`replan` 引擎自身不读时钟，时间戳由调用方注入。

### 防雪崩三断言

1. 单次重排后未来 7 天负载增幅 ≤ 20%
2. **任何情况下不得清空弹性位**
3. 连续 3 次重排未改善 → 停止并转目标校准

四级策略（L1 顺延 → L2 压缩 → L3 替代 → L4 放弃）**有序执行**，首个通过校验的级别即停止，不追求把计划排满。

### 归因判定顺序即优先级

固定为：计划过载 → 执行中断 → 效率不足 → 外部干扰。先排除计划问题再归因用户侧——把「过载」误判为「执行力不足」，系统就会加压。

### LLM 只做表述层

对话层的意图识别是关键词匹配，排程结果本身必须可复现。产品上线时该层由模型承接，但模型只做「结构化结果翻译成人话」与「自然语言转参数修改」，不参与任何调度计算。

## 与架构文档的差异

| 文档指定 | 本 Demo 实现 | 原因 |
|---|---|---|
| Go 1.22 + Gin | Node.js 22 原生 `http` | Demo 阶段免工具链与部署负担；引擎是纯函数，语言可换 |
| PostgreSQL 16 | 内存存储 `server/store/memory.js` | 本期不引入数据库；存储接口已隔离，替换不影响引擎与路由 |
| Redis 7.2（去重/频控/锁） | 进程内 Map | 同上；去重键语义已在 `replan` 契约中显式化 |
| Flutter / 小程序 / Web 三端 | Web 单端 | 本期只交付 Web Demo |

差异集中在**基础设施层**；领域逻辑（可行性 / 排程 / 重排 / 归因 / 同步协议 / 状态机）与六条硬约束保持一致，为后续按文档栈迁移留出清晰边界。

## API

基址 `http://127.0.0.1:8787/api`。完整契约见 [`docs/HANDOFF.md`](docs/HANDOFF.md) 第 5 节。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/state` | 初始全量状态 |
| POST | `/api/feasibility` | 可行性评估 |
| POST | `/api/schedule` | 排程 |
| POST | `/api/replan` | 四级重排（含快照） |
| POST | `/api/replan/undo` | 撤销重排 |
| POST | `/api/attribute` | 偏差归因 |
| POST | `/api/sessions` | 打卡上报（幂等） |
| GET | `/api/sync?since=N` | 增量拉取 |
| POST | `/api/sync/ops` | 批量上行（≤200） |
