# 诺瓦 Nova · 学生日程助理

一个面向学生的、可运行、可解释、可复现的日程助理 Demo。左侧对话栏用自然语言驱动右侧工作台，后端提供确定性调度引擎与 REST API；**同一套引擎代码**既供后端在线计算，也供前端离线兜底。

> 定位说明：本 Demo 的意图识别是关键词匹配，排程、重排与归因全部由纯函数计算，不调用大模型。相同输入必得相同输出，每个排程决策都附带一句人类可读的理由。

## 核心能力

| 能力 | 说明 |
|---|---|
| 目标落地 | 新建目标（考研 / 考公 / 项目导学）→ 可行性判定 → `R < 0.7` 阻断并给三条校准路径 → 拆解草案可改工时、增删、拖动排序 → 确认生效 |
| 可行性评估 | 由总可用工时 `T` 与需求工时 `D` 求比值 `R`，四档判定：充裕 ≥ 1.2 / 合理 ≥ 0.9 / 偏紧 ≥ 0.7 / 阻断 |
| 自动排程 | 30 分钟粒度装箱；日上限、单科目连续时长、弹性位优先级三条硬约束，违反即不排入 |
| 四级重排 | L1 顺延 → L2 压缩 → L3 替代 → L4 放弃，**有序执行**，首个通过防雪崩校验的级别即停止；支持逐条否决 |
| 重排可撤销 | 重排前写快照，撤销即反向应用快照，**不重算**，保证与重排前逐条一致 |
| 中断挽救 | 连续 ≥ 3 天无记录进入挽救：缺口量化 + 压缩 / 顺延 / 降级三选一，一键生效，零惩罚回归 |
| 偏差归因 | 固定顺序：计划过载 → 执行中断 → 效率不足 → 外部干扰；先排除计划问题，再归因用户侧 |
| 执行记录 | 计时 / 暂停 / 部分完成（25–100%）/ 跳过 / 补录；全部写入幂等 op 队列 |
| 计划交互 | 本周日程块拖动改期（日上限 300 分钟校验）、手动锁定（重排不改动）、显性「重新安排」入口 |
| 周报与数据 | 达成率趋势、科目结构、归因占比、结论/依据/已执行动作三段式周报 |
| 设置与数据 | 可用时段 7×4 网格编辑与批量复制、CSV 导出、删除全部数据（7 天内可恢复） |
| 离线与移动端 | 无后端时降级到本地引擎；≤860px 单列 + 底部导航 + 对话覆盖层 |

三条防雪崩断言（同时成立才采纳重排）：

1. 单次重排后未来 7 天负载增幅 ≤ 20%
2. 任何情况下不得清空弹性位
3. 连续 3 次重排未改善 → 停止并转目标校准

## 快速开始

### 方式一：只开前端（无需任何环境）

双击 `index.html`。浏览器直接以 `file://` 打开，脚本走本地引擎，**全部功能可用**，顶栏显示「离线 · 本地计算」。

### 方式二：前后端完整运行

```bash
npm start     # 启动服务，默认 http://127.0.0.1:8787
npm test      # 引擎单测 + HTTP 冒烟
```

打开 `http://127.0.0.1:8787/`。该服务同时静态托管前端，前端与 API 同源，顶栏显示「本地优先 · 已同步」。

### 环境要求

- Node.js **22+**（仅 `npm start` / `npm test` 需要；双击打开 `index.html` 不需要任何环境）
- **零第三方依赖**：只用 `node:http`、`node:fs`、`node:path`、`node:url` 等内置模块，无需 `npm install`

### 端口与绑定地址

| 环境变量 | 缺省 | 说明 |
|---|---|---|
| `PORT` | `8787` | 服务监听端口 |
| `HOST` | `0.0.0.0` | 监听地址；仅本机访问可设为 `127.0.0.1` |

```bash
PORT=8080 HOST=127.0.0.1 node server/main.js
```

## 使用指引

### 界面结构

- **顶栏**：品牌、主导航（今日 / 计划 / 数据 / 我的）、同步状态与日程引擎状态。按 `/` 聚焦输入框。
- **左栏 · 对话区**：输入自然语言，或点下方快捷语句。
- **右栏 · 工作台**：随对话或顶栏导航切换；目标、阶段与 `R` 值显示在工作台头部。
- **渐进披露**：每页只保留首要信息，次要内容默认收起——今日「偏差信号」、计划「阶段与计划项」、数据「趋势与归因」、我的「数据与隐私 / 显示与动效」。点击标题行展开或收起，展开态写入本机（zx.folds），刷新后保持。

### 四个视图

| 视图 | 内容与可用操作 |
|---|---|
| 今日 | 任务卡、达成率、弹性位。开始后可暂停 / 继续；结束后选 25–100% 完成度与状态；未开始可跳过；区标题「补录」可事后记录；偏差信号默认收起 |
| 计划 | 新建目标 / 重新安排；可行性 `R` 与四档刻度、「本周日程块」（拖动改期、锁定）、未来 7 天负载；阶段结构与计划项默认收起 |
| 数据 | 本周概览、三段式周报与预置调整优先展示；8 周趋势、科目结构、偏差归因默认收起 |
| 我的 | 可用时段 7×4 网格（点选 / 复制到工作日 / 清空 / 恢复默认）、通知开关优先展示；数据与隐私（CSV 导出、删除与 7 天恢复）、显示与动效（网格 / 辉光 / 字号）默认收起 |

### 对话指令

关键词命中即触发，无需固定句式：

| 你说 | 效果 |
|---|---|
| 新建目标 / 定目标 / 改目标 | 打开「设定你的目标」四步流程 |
| 我断了四天 / 中断 / 挽救 | 进入中断挽救，缺口量化后三选一 |
| 今天学什么 / 安排 / 任务 | 列出今日任务与剩余时长 |
| 我的计划可行吗 / R 值 / 来得及吗 | 输出可行性评估与判定档位 |
| 这周落下了 / 帮我重排 / 来不及 / 崩了 | 走四级重排，给出策略、diff 与负载变化 |
| 撤销 / 恢复 / 撤回 | 回滚上一次重排 |
| 数学多给两小时 / 加时间 | 调整单科配额并重算 |
| 生成周报 / 复盘 / 这周怎么样 | 输出周报 |
| 我有点累 / 状态不好 / 压力 | 降载：把低权重项顺延到弹性位，不计断更 |
| 开始 / 计时 / 专注 | 对当前任务启动计时 |

未命中任何关键词时返回兜底说明，不臆造结果。

### 已知边界

- 业务状态在内存中，刷新页面回到种子数据；目标、改期、锁定只写本机 op 队列，未接后端持久化。
- 种子数据为单人演示账户，无账号体系与鉴权，不适合直接作为多用户服务使用。
- 通知开关仅记录意图，不实际投递推送；CSV 导出为浏览器本地生成，不经过服务端。
- 删除全部数据会先在本机留存 7 天快照，恢复入口在「我的」。

## 目录结构

```
.
├── index.html                # 前端入口，支持 file:// 双击打开
├── assets/
│   ├── css/app.css           # 样式（单一来源，CSS 变量驱动）
│   └── js/
│       ├── api.js            # 后端通信 + 超时降级 + op 队列
│       ├── engine.js         # 引擎桥接（后端优先 → 本地引擎 → 内置兜底）
│       ├── state.js          # 应用状态
│       ├── assistant.js      # 对话意图路由与重排流程
│       ├── ui.js             # 共享 UI 原语：弹层 / 确认 / 轻提示
│       ├── util.js           # 通用工具与视觉偏好
│       ├── main.js           # 引导、事件绑定、移动端导航
│       ├── flows/            # 目标落地 / 中断挽救 / 执行记录 / 计划交互 / 设置
│       └── views/            # 今日 / 计划 / 数据 / 我的 四视图
├── shared/
│   ├── engine/               # 确定性引擎（双模 UMD，前端只读引用）
│   │   ├── feasibility.js    # 可行性评估：T / D → R 与判定
│   │   ├── schedule.js       # 排程装箱（硬约束 + 弹性位）
│   │   ├── replan.js         # 四级重排 + 快照撤销
│   │   └── attribute.js      # 偏差归因（固定判定顺序）
│   └── data/seed.js          # 共享种子数据
├── server/
│   ├── main.js               # HTTP 入口（API + 静态托管 + CORS）
│   ├── api/routes.js         # REST 路由
│   └── store/memory.js       # 内存存储
├── test/
│   ├── engine.test.js        # 引擎单测（node:test）
│   └── api.test.js           # HTTP 端到端冒烟
└── docs/
    ├── ARCHITECTURE.md       # 架构说明
    ├── HANDOFF.md            # 前后端接口契约（含完整字段定义）
    └── FRONTEND-CONTRACT.md  # 前端分阶段协作契约与交接日志
```

`shared/` 下全部为纯函数模块：不读时钟、不读随机数、不做 I/O，采用 UMD 形态以同时支持浏览器 `<script>` 与 Node `require()`。

## API

基址 `http://127.0.0.1:8787/api`，全部返回 JSON。字段级契约见 [`docs/HANDOFF.md`](docs/HANDOFF.md) 第 5 节。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/health` | 健康检查 |
| GET | `/api/state` | 初始全量状态 |
| POST | `/api/feasibility` | 可行性评估 |
| POST | `/api/schedule` | 排程 |
| POST | `/api/replan` | 四级重排（含快照） |
| POST | `/api/replan/undo` | 撤销重排 |
| POST | `/api/attribute` | 偏差归因 |
| POST | `/api/sessions` | 打卡上报（按 `opId` 幂等） |
| GET | `/api/sync?since=N` | 增量拉取 |
| POST | `/api/sync/ops` | 批量上行（单批 ≤ 200） |
| GET | `/api/reports/weekly` | 周报 |

错误统一返回 `{ error: { code, message } }`。
