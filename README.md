# 诺瓦 Nova · 学生日程助理

## 项目简介

面向学生的、可运行、可解释、可复现的日程助理 Demo：左侧对话栏用自然语言驱动右侧工作台，后端是确定性调度引擎 + REST API，**同一套引擎代码**既供后端在线计算，也供前端离线兜底。

> **定位**：意图识别是关键词匹配，排程 / 重排 / 归因全部由纯函数计算，**不调用大模型**——相同输入必得相同输出，每个排程决策都附一句人类可读的理由。
>
> **能力**：目标落地与可行性判定（`R` 四档，`< 0.7` 阻断并给校准路径）、30 分钟粒度自动排程、四级重排（L1 顺延 → L2 压缩 → L3 替代 → L4 放弃）与快照撤销、连续 ≥ 3 天无记录的中断挽救、偏差归因、执行记录与周报、7×4 可用时段设置、离线与移动端适配。助理人格「诺瓦」的九态形象贯穿界面，设定见 [`docs/IP-DESIGN.md`](docs/IP-DESIGN.md)。

## 快速部署与使用

### 方式一：只开前端（零环境）

双击 `index.html`，浏览器以 `file://` 打开即走本地引擎，全部功能可用，顶栏显示「离线 · 本地计算」。

### 方式二：前后端完整运行

```bash
npm start     # 启动服务，默认端口 8787
npm test      # 引擎单测 + HTTP 冒烟
```

打开 `http://127.0.0.1:8787/`：服务同时静态托管前端，前后端同源，顶栏显示「本地优先 · 已同步」。

**环境要求**：Node.js **22+**（仅 `npm start` / `npm test` 需要，双击打开 `index.html` 不需要任何环境）；**零第三方依赖**——只用 `node:http` / `node:fs` / `node:path` / `node:url` / `node:crypto` 等内置模块，无需 `npm install`。

| 命令 | 作用 |
|---|---|
| `npm start` | 启动 HTTP 服务（API + 静态托管前端） |
| `npm test` | 引擎单测 + HTTP 端到端冒烟 |
| `npm run build:engine` | 由 `shared/engine/*.js` 生成浏览器引擎产物（**改过引擎必须重跑**） |
| `npm run audit` | CSS 审计 |

### 环境变量

本项目不自动读取 `.env`（零第三方依赖），请通过 shell 或系统环境变量注入；清单见 [`.env.example`](.env.example)（只含变量名与说明，无真实值，`.env` 已被 `.gitignore` 忽略）。

| 变量 | 缺省 | 说明 |
|---|---|---|
| `PORT` | `8787` | 监听端口（`server/main.js` 的 `DEFAULT_PORT`） |
| `HOST` | `0.0.0.0` | 监听地址（`DEFAULT_HOST`）；本机自用建议显式设 `127.0.0.1` |
| `NOVA_AUTH_SECRET` | 本地随机 / 生产必填 | 凭证 HMAC 密钥，需 ≥32 字节随机串；`NODE_ENV=production` 未配置直接拒绝启动 |
| `NOVA_TRUST_PROXY` | 未设置 | 置于网关 / 反代之后时设为 `1`，按 `X-Forwarded-For` 最后一跳隔离限流桶；不设则按不可伪造的 TCP 对端地址 |
| `NODE_ENV` | 未设置 | 设为 `production` 启用生产约束（鉴权密钥必填等） |

> 缺省值以 `server/main.js` 为准：`.env.example` 里的 `PORT=8080` / `HOST=127.0.0.1` 是示例取值，不是缺省。缺省绑定 `0.0.0.0`，启动横幅打印 `http://0.0.0.0:8787`，浏览器请用 `http://127.0.0.1:8787/` 访问。

### 使用指南

顶栏为品牌、主导航（**对话 / 今日 / 计划 / 数据 / 我的**）与同步状态。**对话是主页面**：输入自然语言或点快捷语句，诺瓦驱动其余工作台子页，消息历史跨页签保留。

| 视图 | 内容与操作 |
|---|---|
| 今日 | 任务卡、达成率、弹性位；可暂停 / 继续，结束后选 25–100% 完成度与状态，未开始可跳过，另有「补录」 |
| 计划 | 新建目标 / 重新安排；可行性 `R` 与四档刻度、本周日程块（拖动改期、锁定）、未来 7 天负载 |
| 数据 | 本周概览与三段式周报；8 周趋势、科目结构、偏差归因 |
| 我的 | 可用时段 7×4 网格、通知开关、CSV 导出、删除数据（7 天内可恢复）、显示与动效 |

常用指令（关键词命中即触发，无需固定句式）：

| 你说 | 效果 |
|---|---|
| 新建目标 / 定目标 | 打开「设定你的目标」四步流程 |
| 我断了四天 / 中断 / 挽救 | 进入中断挽救，缺口量化后三选一 |
| 今天学什么 / 安排 / 任务 | 列出今日任务与剩余时长 |
| 我的计划可行吗 / R 值 / 来得及吗 | 输出可行性评估与判定档位 |
| 这周落下了 / 帮我重排 / 来不及 / 崩了 | 走四级重排，给出策略、diff 与负载变化 |
| 撤销 / 恢复 / 撤回 | 回滚上一次重排 |
| 生成周报 / 复盘 / 这周怎么样 | 输出周报 |
| 确认放弃 | 确认采纳含「放弃」项的重排（L4 经确认才生效） |

未命中任何关键词时返回兜底说明，不臆造结果。

### 使用前须知

- **数据不持久化**：后端为内存态，服务重启后回到种子数据；新目标与打卡记录只在本机（`zx.overlay`）存活，改期与锁定未接服务端持久化。
- **单人演示账户**：已内置 Bearer 凭证鉴权（由 `POST /api/auth/session` 签发），但无注册 / 多用户体系。
- 通知开关仅记录意图、不实际投递；CSV 导出为浏览器本地生成；页面无第三方脚本、无埋点、无 Cookie。
