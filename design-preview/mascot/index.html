01概念与主立绘

小序是 诺瓦 Nova 的助理人格：确定性引擎的「脸」。名字三关义——秩序（给日程立秩序）、时序（时间安排）、序章（大学生活的开始）。v2 按超能NoNo原设轮廓重画：球形机身 + 双耳天线 + 大面罩；初版方盒方案归档于 mascot-v1-box.svg。

设计转译（v2）

悬浮小管家 → 球形机身 + 纸影悬浮。不画推进器与脚，底部纸影表达「轻」。

屏幕脸 → 大面罩 + 竖胶囊眼。情绪全部由眼形承载；产品内用暖墨面罩 + 琥珀眼。

天线 → 双耳天线。外八微弯、发光内条纹；专注计时变朱砂，对齐「朱砂=正在进行」。

多功能整合 → 侧盘 + 朱砂「序」印。耳机状浮游侧盘对应 NoNo 的集成结构；印章是顶栏 .seal 的延续。

「不催你，只是把路铺好。」——小序的语气底线

复刻边界：轮廓类别致敬原设，细节全部原创——耳形曲线、面罩形状、比例、配色构型均与原设不同构，胸口朱砂印为身份锚点（是小序，不是 NoNo）。不做一比一描摹复制：仓库为 MIT 协议且 demo 公网部署，复刻淘米版权形象构成侵权。

06绘制与使用规则

  • 圆润球身：轮廓为球形 + 小圆角面罩，禁改回方形或加棱角（初版方盒方案已归档 mascot-v1-box.svg，仅作历史参考）。
  • 去发光：产品内（琥珀涂装）平涂 + 暖墨发丝线；眼睛、耳条纹是「亮色」不是「发光」，禁止外光晕。原味涂装仅允许眼与耳的微光描边。
  • 朱砂纪律：#9C3B2B 只出现在「正在进行」语义（专注态耳与进度环、印章），不参与装饰。
  • 情绪范围：只允许「平静—关切—欣喜」三档，禁止大笑、哭泣、愤怒等强情绪（反焦虑）。
  • 最小形：≤20px 时退化为「暖墨底 + 双耳与双眼」（见 favicon），不再保留身体细节。
  • 涂装分工：琥珀涂装进产品 UI；原味涂装（银白 + 藏青 + 青蓝）只用于表情包、周边与宣传物料，不进产品界面。
  • 版权红线：禁止与《赛尔号》NoNo 原设做拼贴、换色、描摹、二改混用；衍生绘制保持本页的原创细节差异。
风格参考仅限轮廓类别与气质（球形悬浮助手 · 以脸传情 · 有情绪需要照顾的陪伴感），形象为原创演绎，不复制、不使用《赛尔号》/ 超能NoNo 的造型、配色与命名（超能NoNo 为淘米网络 IP）。参考资料： 百度百科 · NONO（人工智能辅助系统） · 赛尔号官网 · 超能NONO · 4399 · 超能NONO进化图（原设参考图来源）。 设定文档见 docs/IP-DESIGN.md · 2026-11-11（v2）
