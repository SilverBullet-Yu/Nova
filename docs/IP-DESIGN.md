# 诺瓦 · IP 形象设定（v4）

> 「诺瓦 Nova」的视觉 IP 规范。本文件只描述**当前 v4 形象的实际规范**。
> 唯一事实来源：[`scripts/build-mascot-v4.js`](../scripts/build-mascot-v4.js)（几何与色板）、[`assets/img/`](../assets/img/)（实际产出）、[`assets/css/app.css`](../assets/css/app.css)（产品主题色）、[`assets/js/`](../assets/js/)（接入点）。
> 历史方案（v1 / v2 / v3）已不作为规范。

## 1. 名字与人格

### 1.1 名称与身份锚点

- 产品名与助理同名：`诺瓦 Nova`。页面标题为「诺瓦 Nova · 大学生日常助理」，顶栏品牌区为「Nova诺瓦 / 大学生日常助理」（`index.html`）。
- 助理侧消息署名固定为「诺瓦」，用户侧署名为「你」（`assets/js/assistant.js`）。助理消息右下角有朱砂「诺」印落款 `.seal-no`（14×14，`--cinnabar` 底 + `--ac-ink` 字）。
- 形象身上的身份锚点是胸口 14×14 朱砂方印「诺」字（`assets/img/mascot-v4.svg`），与消息落款印同构。

### 1.2 性格定位（对应可验证的产品行为）

| 性格 | 在产品里的落点 | 证据 |
|---|---|---|
| 确定性 | 同一输入必得同一输出，排程可复现 | `README.md`、`shared/engine/` |
| 给理由 | 排程与重排决策都带一句 `reason` | `shared/engine/replan.js`、`shared/engine/feasibility.js` |
| 兜底诚实 | 关键词未命中就直说没接住，不臆造结果 | `assets/js/assistant.js` 的 `fallback()`（对应状态 ⑨） |
| 不催促 | 只陈述事实与选项；九种表情的情绪上限是「平静—关切—欣喜」 | 状态系统（§4） |

### 1.3 说话风格约定

- 短句、口语、不卖萌；`assets/js/` 全部话术不使用感叹号。
- 调整计划时给理由（对应引擎 `reason`），不只报结论；听不懂就直说不知道，并列出已支持的动作类别（`fallback()` 的既有行为）。
- 自称「诺瓦」；用户侧署名为「你」。

### 2.3 描边与配色使用规则

- 机身不加粗勾线；分缘靠明暗（暗部 + 高光）与 1px 冷边线。面罩的 5px 描边是全片唯一粗描边。
- 眼与耳条纹是「亮色」不是「发光」：不画 glow、不画渐变、不加投影。
- 朱砂只出现在「正在进行」语义（专注态的耳、面罩描边、进度环）与身份锚点（胸口印、消息落款印）。
- 各状态之间只改四样：面罩里的脸、涂装色板、状态装饰、耳的色相与透明度；机身 / 面罩 / 耳杆 / 关节盘 / 「诺」印的骨架各态一致。

### 2.4 经典版与产品版

同一几何、两套皮肤，差异只在色板：产品版为墨蓝涂装（机身 `#FFFFFF`、面罩 `#1A2230`、描边与眼 `#4C7FD0`、关节盘 `#E7ECF3`），经典版为原味涂装（机身 `#F7FAFB`、面罩 `#05070B`、描边与眼 `#2FE3F2`、关节盘 `#FFFFFF`），完整色值见 §3.2 与 §3.3。两版的朱砂「诺」印同色（`#A03B2C`）。

经典版还原「球形机身 + 亮青光柱耳」的周边气质，只用于表情包、周边与宣传物料，**不进产品界面**。

衍生层（`--ac-a02`…`--ac-a72`、`--warn-a*`、`--bad-a*`、`--ok-a*`）由 `color-mix()` 从基础色派生，换肤只改 `:root` 基础值。

**主题色与形象用色不是同一套值**，分三种关系：

- 同源同值：`--bg #FBF7EF` = `favicon-v4.svg` 底色 = `index.html` 的 `<meta name="theme-color">`；`--cinnabar #A03B2C` = 胸口「诺」印 = 专注态的朱砂描边与进度环。

- 形象侧独立档：提醒态耳的 `#274B94` 是深墨蓝深化档，既不等于 `--warn #8A5A1E`，也不等于形象主色 `#4C7FD0`。

## 5. 产品接入

### 5.1 生成与来源

- 全部 14 个 SVG 由 `node scripts/build-mascot-v4.js` 生成到 `assets/img/`（脚本零依赖，只写该目录，不读其它目录）。该命令不在 `package.json` 的 scripts 里，需直接用 node 执行；重新生成的结果与仓库内文件逐字节一致。
- 素材只走本地相对路径，不加载第三方资源。

### 5.2 favicon 与首屏形象

| 位置 | 引用方式 | 尺寸 |
|---|---|---|
| 标签页 / 桌面图标 | `index.html`：`<link rel="icon" href="assets/img/favicon-v4.svg" type="image/svg+xml" />` | 16×16，底色 `#FBF7EF` |
| 顶栏品牌标记 `.seal` | `index.html`：`<img src="assets/img/avatar-v4.svg" width="26" height="26" alt="" />` | 26×26 |
| 顶栏对话入口 `.cp-open` | `index.html`：`<img src="assets/img/avatar-v4.svg" width="22" height="22" alt="" />` | 22×22 |
| 对话欢迎语首屏 | `assets/js/main.js` `greetingHtml()`：`<img class="msg-mascot" src="assets/img/mascot-v4.svg" width="132" height="116" alt="诺瓦" />` | 132×116 |

`favicon-v4.svg` 的底色与 `<meta name="theme-color" content="#FBF7EF">` 同值，与 `--bg` 一致。

### 5.3 状态图的使用位置

见 §4 表。对应样式类在 `assets/css/app.css`：`.msg-mascot`（132×116）、`.msg-state` / `.msg-state.state-calc`（32×28 / 24×21）、`.tk-mascot`（24×30）、`.sb-mascot`（32×28）、`.warn-flag`（22×19）。助理消息落款印由 `.seal-no` 渲染（`--cinnabar` 底 + `--ac-ink` 字），不占用独立素材。

### 5.4 动效归属

SVG 内不含任何动画（经 `<img>` 引用也读不到页面上的 `data-motion` 开关）；动效只加在产品侧的 `img` 元素上：漂浮 `novaFloat`、呼吸 `novaBreathe`、到场 `novaEnter`、盖章 `novaStamp`、弹跳 `novaPop`、歪头 `novaWobble`、摇头 `novaShake`。总闸唯一：`html[data-motion="off"]`（`assets/css/app.css`）。

## 6. 禁用清单

- 禁止手改 `assets/img/` 下的任何 SVG：素材是 `scripts/build-mascot-v4.js` 的产物，手改会被下一次生成覆盖；要改造型就改生成脚本再重新生成。
- 禁止把 `mascot-v4-classic.svg`（原味涂装）接入产品界面；它只用于表情包、周边与宣传物料。
- 禁止给眼、耳透镜、耳杆加 glow / 渐变 / 投影：它们是「亮色」不是「发光」。
- 禁止用朱砂做装饰（按钮底色、贴纸、边框）；朱砂只承担「正在进行」语义与身份锚点（胸口印、消息落款印）。
- 禁止更换机身轮廓语言：椭圆机身 + 斜向细长光柱耳 + 椭圆大面罩 + 竖条眼是识别度所在，不改回方盒、不加棱角；也禁止给机身加粗勾线（分缘靠明暗与 1px 冷边线）。
- 禁止在 SVG 内写动画或自己做动效判断：动效统一在产品侧，总闸是 `html[data-motion="off"]`。
- 禁止对《赛尔号》超能 NoNo 原设做描摹、拼贴或换色混用；本形象为原创构型，生成脚本与产出的 SVG 内均标注了该边界。
