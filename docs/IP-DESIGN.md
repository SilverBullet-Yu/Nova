## 1. 名字与人格

**诺瓦 NOVA**（顶栏 `.seal`、对话栏 `.avatar` 现用形象即其符号；胸口朱砂印取「诺」字）。名字三关义：

| 字义 | 对应产品 |
|---|---|
| 承诺 | 说到的就做到：同一输入必得同一输出，排程可复现、可解释（引擎的确定性） |
| 一砖一瓦 | 30 分钟粒度把日程垒起来；日常屋瓦，遮风挡雨（陪伴感、反焦虑） |
| 新星 | Nova 拉丁语义为「新」：每天重新开始，不评判昨天，只排今天 |

与产品名同源：诺瓦 Nova 的「纳」与「诺」同音，助理即品牌的人格化。

**人格即产品**：确定性、可解释、零惩罚。人格关键词——

- **不催促**：只陈述事实与选项，不评判、倒计时不用红色恐吓；
- **给理由**：每个排程决策附带一句人话（对应引擎的 reason 字段）；
- **兜底诚实**：未命中关键词就说不理解，不臆造（对应状态 ⑨）。

语气底线一句话：**「不催你，只是把路铺好。」**

## 2. 参考转译：超能NoNo → 诺瓦（v4）

原设拆解（《赛尔号》超能NoNo 官方立绘）：白色椭圆机身、深色大面罩 + 亮色粗描边、两根发光竖条眼与右上反光片、两条细长锥形光柱耳（左斜约 46°、右近垂直约 18°）、球体左下外挂小圆点、周身淡色飞溅碎片、几乎无轮廓线条。

v4 的做法：**把原设的造型语言整体搬到诺瓦身上，但每一个具体形状都是重画**——不是描摹官方像素，而是用同一套设计语汇重新构造。几何比例经对官方立绘的像素测量标定（画布 240×300 坐标系）。

| 超能NoNo 的造型语言 | 诺瓦 v4 的转译 | 为什么这样转 |
|---|---|---|
| 白色椭圆机身（近乎无线条） | 椭圆机身 cx130 cy142 rx55 ry47，右下淡影、左上柔光，无描边 | 保留圆润悬浮的轮廓类别；淡影替代勾线，靠明暗分缘 |
| 深色大面罩 + 亮色粗描边 | 椭圆面罩 cx138 cy141 rx34 ry35，**顺时针倾 20°**，5px 墨蓝描边 | 保留「以脸传情」；描边把原设的发光屏转译为产品的活性色 |
| 两根发光竖条眼 | 竖胶囊眼 7×24（左）与 6.5×22（右），右眼更高 | 保留原设「双竖条」读感与倾斜关系，产品内用墨蓝 |
| 面罩右上反光片 | 31×23 圆角斜片压住右眼上部 | 复刻原设的玻璃反光与光感层次 |
| 细长锥形光柱耳（左 46° / 右 18°） | 双耳为**三段递减、由实到淡**的锥形光柱（根 11.5→尖 2.2 / 9.5→尖 1.8），耳根扎入球体、嵌沿杆轴的深色透镜与落球面的白色关节盘 | 全片最标志性特征；原设耳朵本身即半透明发光体，用分段叠加而非渐变实现 |
| 球体左下外挂小圆点 | 同一位置换成**朱砂方印「诺」** | 原设的挂载点位置，换成本产品的身份锚点 |
| 周身淡色飞溅 | 左下与右侧的淡墨蓝碎片（6 片，深浅两档） | 保留原设的悬浮动势与破碎感 |
| —（原设没有） | 无口、无推进器、无厚勾线 | 克制：细节让位于轮廓与表情 |

**复刻边界（为什么不做一比一描摹）**：超能NoNo 是淘米网络的版权形象；本仓库采用 MIT 协议且 demo 已公网部署，放入描摹复刻的形象构成侵权暴露。因此本设定只借用「轮廓类别 + 造型语汇」，所有具体形状均为手工重绘的原创构型，并保留朱砂「诺」印作为与小序绑定的身份锚点。

**双涂装**：同一几何，两套皮肤——
- **墨蓝涂装**（`mascot-v4.svg`）：纸白机身 + 墨蓝黑面罩 + 墨蓝眼耳描边，产品 UI 内使用，守治学色彩纪律；
- **原味涂装**（`mascot-v4-classic.svg`）：近白机身 + 纯黑面罩 + 亮青描边与发光眼耳，还原赛尔号气质，只用于表情包、周边、宣传物料，**不进产品界面**。两版均保留朱砂印。

## 3. 造型规范（v4，画布 240×300）

**结构**（自下而上）：地面投影 → 飞溅碎片 → 双光柱耳（根透镜 + 关节盘）→ 椭圆机身 → 大面罩（描边 + 竖条眼 + 反光片）→ 外挂朱砂「诺」印。

| 项 | 规范 |
|---|---|
| 画布 | 主立绘 240×210（viewBox 同）；脸形头像 96×96；应用图标 16×16 |
| 机身 | 椭圆 cx130 cy142 rx55 ry47；右下淡影、左上柔光；**不加描边** |
| 面罩 | 椭圆 cx138 cy141 rx34 ry35，旋转 20°；描边 5px（墨蓝 / 亮青） |
| 眼 | 竖胶囊：左 7×24 @ y131、右 6.5×22 @ y122；各带一条亮芯高光 |
| 反光片 | 31×23 圆角矩形，置于面罩内右上、压住右眼上缘 |
| 左耳 | 根部 (98,108)（**扎入球体轮廓内**，光柱自球面探出）→ 尖端 (28,30)，倾角约 48°；根部半宽 11.5、尖端 2.2；三段递减不透明度（.94 / .55 / .28，阶梯放缓以消除「断成两截」读感） |
| 右耳 | 根部 (128,100)（扎入球体）→ 尖端 (152,16)，倾角约 16°（自竖直）；根部半宽 9.5、尖端 1.8；耳根深色透镜**沿杆轴** + 白色关节盘落在光柱穿出球面的交点上 |
| 耳根透镜 / 关节盘 | 透镜沿各自杆轴方向的窄椭圆：左 (91,100.2) rotate 48°、右 (131.4,88.2) rotate −74°；关节盘：左 (95.5,105.5) r5.5、右 (129.5,95.5) r5（均贴球面） |
| 身份锚点 | 14×14 朱砂方印「诺」，中心 (85,171)（球体左下外挂点） |
| 飞溅 | 6 片椭圆碎片，左下 4 片（倾角 −18°~−26°，同一漂离方向）+ 右侧 2 片（+24°~+26°），两档透明度；角度分组统一，读作悬浮气流而非污点 |
| 线条 | 无粗勾线；分隔靠明暗与描边；纸白机身外加 1px 淡冷边线（`rgba(18,26,40,.10)`），在纸白底上仍可辨 |
| 最小形 | ≤20px 退化为「脸」形：纸白底 + 深色面罩 + 两条墨蓝竖眼 + 双耳尖，不保留身体细节与朱砂印 |

## 4. 配色规范

### 产品主题色：纸白 + 墨蓝（v4 换肤后的唯一色板，定义在 `assets/css/app.css` 的 `:root`）

> **UI 视觉语言（2026-11-14 起）：日漫清晰线（二次元日漫 × 清晰线骨架）**——漫画描边语言保留（主容器 2px 实墨线全框、无弥散阴影、标题超重黑体），形状与色板日漫化：`--r:10px` 圆润体系、对话为云朵圆角气泡 + 圆月牙尾巴（用户侧天空蓝平涂反白）、当前页签天空蓝平涂圆角块、底纹为网点 halftone、banner 右上角 repeating-conic 集中线；「你 = 樱花粉圆点、诺瓦 = 天空蓝圆点」的说话人对位。诺瓦素材不动——圆润机身住进圆润分格，风格差进一步收窄。详见 `docs/FRONTEND-CONTRACT.md` 同名章节。

**接入原则**：素材只走本地文件（页面承诺不加载第三方资源）；不改动原有布局与网格，形象以「替换既有字块」的方式最小侵入；状态切换不依赖事件派发（CSS `:has()` 直读焦点态 + JS class 双保险）。

**灵动（产品侧动效，2026-11-14 起；2026-11-15 扩展）**：素材本身保持静态——SVG 经 `<img>` 引用读不到页面上的 `data-motion` 开关，**SVG 内不做动画**；动效只加在产品侧 img 元素上，全部为整图位移/缩放/旋转（无发光、无渐变，情绪上限仍是「平静—关切—欣喜」）。档位纪律：**常驻循环只保留漂浮 / 呼吸两类**（低速小幅）；状态反应全部为一次性动效，元素出现时自动播完，不添燥感：

| 动效 | 类型 | 目标 | 参数 |
|---|---|---|---|
| 漂浮 `novaFloat` | 循环 | 欢迎语主立绘 `.msg-mascot`（接力）、计算中 `.msg-state.state-calc`、挽救横幅 `.sb-banner .sb-mascot`（慢速 4.6s） | translateY 0→−3px 往复，3.6s / 2.6s / 4.6s ease-in-out |
| 呼吸 `novaBreathe` | 循环 | 计时中的任务行 `.tk-mascot`（专注态） | scale 1→1.06 往复，2.4s ease-in-out |
| 到场 `novaEnter` | 一次性 | 欢迎语主立绘（入场后 .5s 无缝接力漂浮） | translateY 10px→0 + scale .96→1 + 淡入，.5s |
| 盖章 `novaStamp` | 一次性 | 助理消息「诺」印落款 `.seal-no` | scale 1.6→1 + rotate −14°→−2.5° + 淡入，.32s；**收尾帧与静态微旋精确衔接** |
| 弹跳 `novaPop` | 一次性 | 任务完成消息 `.msg-state.state-done`、挽救完成横幅 `.sb-banner-ok .sb-mascot` | scale .5→1.14→.95→1 弹性，.55s |
| 歪头 `novaWobble` | 一次性 | 兜底回复 `.msg-state.state-unknown` | rotate 0→−6°→4°→0，.7s |
| 摇头 `novaShake` | 一次性 | 提醒旗标 `.warn-flag`（归因面板 / 负载预警） | rotate 0→±6° 内三摆，.65s |
| 品牌回应 | hover | 顶栏 `.seal img` / `.cp-open img` | scale 1.08 + rotate ∓4°，.22s transition |

受两道既有总闸约束：`html[data-motion="off"]` 与 `prefers-reduced-motion: reduce` 均会 `animation:none!important`（hover 的 transition 也被降级到 .01ms），动效关闭后素材退回静态——与契约「所有动效必须可关闭」一致。预览：`design-preview/mascot/preview-v4.html` §07「灵动」（每式带重播按钮）。

## 7. 禁用清单

- 禁止大笑、哭泣、愤怒等强情绪表情（反焦虑，情绪只允许平静—关切—欣喜三档）；
- 禁止给眼睛 / 耳透镜加发光、渐变、投影（原味涂装仅允许眼与耳的微光描边）；
- 禁止朱砂色用于非「正在进行」装饰（如按钮、贴纸底色）；
- 禁止改回方形机身或加棱角——椭圆机身与斜向光柱耳是 v4 的识别度所在；
- 禁止给机身加粗勾线（原设几乎无线条，靠明暗分缘）；
- **版权红线**：禁止对《赛尔号》NoNo 原设做描摹、拼贴、换色、二改混用；任何衍生绘制必须保持本设定的原创细节差异（耳杆构造、面罩倾角与比例、反光片、朱砂印）。

## 8. 验证方式

- 素材：`node scripts/build-mascot-v4.js` 重新生成后，用 Chrome headless（`--headless=new --screenshot`）逐张截图人工核验；
- 接入：启动 `npm start` 后用 CDP 驱动真实浏览器，检查图片 `naturalWidth > 0`、聆听态切换（`is-listen` + 可见性）、专注态 `.tk-mascot` 存在、移动端无横向溢出、控制台无报错；
- 回归：`npm test`（引擎单测 + HTTP 冒烟）全绿；`npm run build:cloudbase` 确认 `assets/img/` 进入部署包。
